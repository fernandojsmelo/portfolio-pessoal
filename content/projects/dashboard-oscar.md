## O problema

Explorar quase um século de indicações e vencedores do Oscar de forma
visual, em vez de vasculhar tabelas estáticas.

## Decisões técnicas

Dashboard interativo em Python com Streamlit, lendo os dados históricos
diretamente de arquivos locais — sem necessidade de um backend separado
para um dataset desse tamanho. Documentação do funcionamento incluída no
próprio repositório.
